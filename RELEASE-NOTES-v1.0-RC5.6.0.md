# ScopeLogic v1.0 RC5.6.0

This release introduces proposal revision lifecycle and document-specific official release tracking.

- Quote inclusion controls and project value summary.
- Side-effect-free proposal preview.
- Official individual proposal archive and revision locking.
- Locked-revision Create Revision workflow with revision reasons.
- Current-database material and labor refresh with manual override preservation and comparison data.
- Revision-specific Scope of Work snapshots carried forward into new revisions.
- Explicit Project Manager labor handling in quote totals and official snapshots.
- Document-identity release histories with separate Generated and Issued metadata.
- Immutable underlying quote revision snapshots for proposal audit history.
- Supabase migration for proposal document identities, release-to-quote revision references, RLS, storage metadata, and atomic release numbering.
