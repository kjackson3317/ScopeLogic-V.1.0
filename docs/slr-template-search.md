# SLR Template Search

The SLR Template Library is designed for a growing reusable-scope catalog.

## Search and filters

- Keyword search covers template name, scope concern, recommendation / bid basis, RFI language, source references, and checklist language.
- System narrows the library to templates assigned to the selected technology system.
- Output narrows the library by reusable downstream action: RBB, GC Clarification, Formal RFI, or Checklist.
- The result counter shows the number of matching templates.
- Selecting a search result updates the existing template selection so the established **Use Template** and **Delete Template** controls remain authoritative.

Templates continue to store reusable scope logic only. Project-specific source references, released numbering, responses, and project history should be completed on the project SLR after applying the template.
